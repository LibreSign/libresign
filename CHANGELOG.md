# Changelog

LibreSign release history is maintained per major release line in [`docs/changelogs/`](docs/changelogs/).

Each file follows the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format used by the Nextcloud App Store.

During App Store packaging, the changelog matching the app major is copied into the package root as `CHANGELOG.md`.
